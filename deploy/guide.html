推荐测试路径

① 完整交易闭环约 3 分钟

  • 新手机号 + 888888 登录 → 我的 → 余额 → 输入充值卡密（找管理员要，或让管理员直接调余额）
  • 首页选玩伴 → 进详情 → 选服务下单 → 选日期时段 → 余额支付
  • 订单页观察自动流转：10 秒接单 → 30 秒服务中 → 90 秒完成
  • 完成后写评价（可带图评分）

② 玩伴视角

  • 用玩伴账号登录（13800001000~06）
  • 我的 → 玩伴工作台：接单/拒单、上下线切换、联系客户
  • 钱包 → 提现 → 切换管理员账号审核打款

③ 分销返佣

  • 账号 A：我的 → 推广中心 → 复制邀请码
  • 账号 B：注册时在登录页填 A 的邀请码（或推广中心手动绑定）
  • B 下单完成 → A 的推广中心看到佣金到账（比例在管理端「设置」调）

④ 管理端巡检

  • 管理员登录 → 管理后台 → 数据页看 15 项指标
  • 玩伴页：审核新申请、设推荐位、强制下线
  • 订单页：搜订单号、强制取消（自动退款退券）
  • 充值卡页：生成卡密 → 复制给用户兑换

⑤ 社交功能

  • 动态页发布动态 → 另一账号点赞/评论/关注
  • 玩伴详情页 →「私聊」发消息 → 消息 tab 看会话和未读
  • 聊天页右上角可拉黑，验证双向屏蔽

功能清单

用户端

  • 玩伴浏览：推荐/最新/评分排序、搜索、详情（相册/服务/评价/动态）
  • 下单：多服务项、时间段选择、优惠券抵扣、余额/模拟支付
  • 订单：催单、取消退款、服务中加钟（子订单）、再来一单
  • 评价：评分+图文，玩伴可回复
  • 社交：动态发布/点赞/评论、关注流、私信聊天、拉黑
  • 钱包：余额、充值卡兑换、账单来源（充值/消费/退款/佣金/提现）
  • 分销：邀请码绑定、佣金明细、下线列表

玩伴端 + 管理端

  • 入驻申请 → 平台审核 → 改资料自动回炉再审
  • 工作台：接单/拒单、上下线、服务与相册管理
  • 收益：完单入账、提现申请、驳回原因可见
  • 看板：用户/订单/GMV/佣金/提现 15 项指标
  • 运营：玩伴推荐位、强制下线、订单仲裁退款、评价动态删除
  • 用户：搜索、禁用（登录拦截）、角色委派、余额调整
  • 营销：优惠券模板、充值卡批量生成、Banner 轮播
  • 系统：佣金比例、敏感词库（热更新）

注意事项

演示环境：万能码 888888 人人可登录，模拟支付不扣真钱，订单自动流转仅用于演示。
数据重置：数据库可随时清空重灌 seed 数据，测试别放真实信息。
已知边界：真实支付/短信/地图需商户凭证，当前为模拟实现；平台抽成比例未启用（玩伴 100% 入账）。
