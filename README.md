# 城市玩伴（地陪 H5）

参考「滇域玩伴」类地陪/玩伴预约平台的自研实现。

## 技术栈

| 端 | 技术 |
|---|---|
| 前端 `web/` | Vue 3 + TypeScript + Vant 4 + Vite + Pinia + Vue Router，移动端 H5（375px 设计稿，px→vw 自适应） |
| 后端 `server/` | NestJS 11 + Prisma 7 + SQLite（better-sqlite3 驱动）+ JWT，REST API |

## 启动

```bash
# 后端
cd server
pnpm install
pnpm db:push      # 初始化 SQLite（dev.db）
pnpm db:seed      # 灌入演示数据（8 个玩伴 + 服务 + 动态 + banner + 优惠券 + SVG 占位图）
pnpm start:dev    # http://localhost:3000

# 前端（另开终端）
cd web
pnpm install
pnpm dev          # http://localhost:5173 ，/api 和 /uploads 已代理到 3000
```

## 已实现功能

**用户端（C 端闭环）**

- 登录：手机号 + 验证码（开发环境验证码接口直接回显 `devCode`），JWT 30 天
- 首页：banner 轮播 / 快捷入口 / 人气推荐 / 最新入驻
- 玩伴列表：关键词搜索、排序（默认/评分最高/最近新人/离我最近）、城市筛选、下拉分页
- 玩伴详情：相册轮播点击预览、实名/平台保障/爽约包退标签、基本信息、服务价目、评价（含玩伴回复）、TA 的动态、关注、站内私信/解锁微信、立即预约
- 下单：多服务份数（最低起购校验）、预约日期、优惠券抵扣、费用明细、协议
- 支付：余额支付（模拟充值）/ 模拟微信支付
- 订单：状态机 `待支付→待接单→待服务→服务中→已完成 / 已取消 / 已拒绝 / 已退款`，催单、取消退款（余额原路退回）、加钟（关联子订单）、再来一单、评价、联系玩伴
- 优惠券：领券中心 / 我的券 / 下单抵扣 / 未支付取消退券
- 动态广场：推荐/关注双流、点赞、评论、发布、图片预览、我的动态管理、敏感词过滤
- 私信：会话列表、气泡聊天（5s 轮询）、未读角标、拉黑双向屏蔽、敏感词过滤
- 我的：资料编辑、头像上传、余额充值、优惠券、关注、消息、我的动态、联系客服（接管理员会话）
- 推广中心：邀请码（注册可填/老用户补绑，只能绑一次）、下线列表、佣金明细（下线完单按比例返佣入余额）

**玩伴端（B 端工作台）**

- 申请入驻：城市/区域/介绍/标签/相册/服务项目编辑，提交后待平台审核（pending→approved 才进公开列表）
- 工作台：上线/休息切换、审核状态提示、待接单/今日/累计统计、收到评价回复
- 订单操作：接单/拒绝/开始/完成、联系客户、10s 轮询
- 钱包：完成订单自动入账、余额提现申请、提现记录

**管理端（平台后台）**

- 数据仪表盘：用户/玩伴/订单/交易额/动态/私信/待提现/已发佣金/评价/用券/禁用统计
- 玩伴：审核（通过/拒绝）、实名标、推荐位（首页+列表加权）、强制上下线
- 用户：昵称/手机号搜索、禁用/启用（禁用拦截登录）、角色变更（不能改自己）、余额调整（正负）、详情（订单/佣金）
- 订单：状态筛选、订单号搜索、强制取消（已支付自动退款+退券）
- 评价：全量列表、违规删除（自动重算玩伴评分）
- 营销：优惠券模板 CRUD（面额/门槛/限量/有效期）、Banner CRUD（图片上传）
- 提现审核：打款/拒绝（拒绝退回余额）
- 设置：分销佣金比例（0-50%）、敏感词库（热更新）、佣金明细总览

**安全/风控**

- 玩伴入驻审核流、敏感词过滤（动态/评论/私信）、双向拉黑、余额支付事务、提现审核、管理端鉴权（AdminGuard）

## 演示模式

`DEMO_AUTO_FLOW`（默认开）：支付后订单自动流转 待接单→10s 已接单→30s 服务中→90s 已完成，配合订单详情页 5s 轮询可看到完整生命周期。关闭：`DEMO_AUTO_FLOW=false pnpm start:dev`。
